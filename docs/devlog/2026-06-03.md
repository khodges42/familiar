# 2026-06-03

Implemented the first Familiar utility slice:

* Python package metadata and console script entry point.
* Runtime `Familiar` API.
* Character loader for plain-file packs.
* Speech bubbles, layouts, and mood fallback.
* CLI commands: `say`, direct character form, `forge`, `pack`, `validate`,
  `preview`, and `forge-preview`.
* ASCII, block, and Braille image renderers with alpha-aware cropping.
* Generated the Proxy example pack from `characters/proxy/source_images/`.
* Added TOML config defaults and release build workflow scaffolding.
* Added a line renderer for edge-based avatar experiments.
* Added an ink renderer for black-on-white line art using quadrant blocks.
* Added optional Chafa rendering through `chafa.py` or the `chafa` CLI.
* Fixed threshold background removal so white/off-white background edges are
  compared with a per-channel color tolerance.
* Restricted Chafa output to broadly supported block, border, Braille, and
  ASCII symbols to avoid tofu boxes from newer Unicode symbol ranges.
* Made layout alignment display-width aware and centered narrow speech bubbles
  under wider avatar canvases.
* Fixed titled speech bubble top borders being one column wider than the body.
